# Third-party data

Glitched downloads and stores data from the sources below. This repository does
not include that data; each user's copy is fetched from the source when they run
the loaders. If you redistribute data from a source (for example, a database
snapshot), follow that source's terms, linked below.

| Source | Used for | Terms |
|---|---|---|
| MITRE EMB3D™ | Embedded-device threats, mitigations, properties | <https://emb3d.mitre.org/> (MITRE terms of use) |
| MITRE ATLAS™ | Attacks on AI systems | <https://github.com/mitre-atlas/atlas-data> (see its LICENSE) |
| NIST National Vulnerability Database (NVD) | CVE records | <https://nvd.nist.gov/developers/terms-of-use>. This product uses the NVD API but is not endorsed or certified by the NVD. |
| Hugging Face Papers | Research paper metadata | <https://huggingface.co/terms-of-service> |
| arXiv | Research paper metadata | <https://info.arxiv.org/help/api/tou.html>. Thank you to arXiv for use of its open access interoperability. |
| NVIDIA Research | Publication metadata | <https://www.nvidia.com/en-us/about-nvidia/terms-of-service/> |

MITRE EMB3D and MITRE ATLAS are trademarks of The MITRE Corporation.
